# RFBrowser 用户操作指南

> 基于验收标准自动生成 | 版本 0.3.0

## 快速开始

### 安装与启动

1. 运行可执行文件启动 RFBrowser
2. 首次启动时选择或创建 Vault（知识库目录）
3. 配置 AI Provider（设置 → AI 设置）

### 三场景工作流

RFBrowser 将知识工作分为三个场景，按 `Ctrl+1/2/3` 切换：

| 场景 | 快捷键 | 用途 |
|------|--------|------|
| Capture（捕捉） | `Ctrl+1` | 浏览网页、剪辑内容 |
| Think（思考）   | `Ctrl+2` | 编辑笔记、深度写作 |
| Connect（连接） | `Ctrl+3` | 知识图谱、发现关联 |

## 核心功能

### 命令栏 — 全局搜索

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+K` | 打开命令栏 |

- 输入关键词搜索所有笔记、标签和命令
- 输入 `/` 触发快速操作（QuickMove）
- 搜索结果按类型分组显示

### 场景一：Capture — 信息捕捉

#### 浏览网页

1. 在顶部地址栏输入 URL 并回车
2. 支持多标签页浏览
3. 应用自动拦截危险 URL（javascript:、file:、data: 等）

#### 剪辑内容

1. 在网页中选中文本
2. 点击底部工具栏的「剪辑」按钮
3. 内容自动保存为 Markdown 笔记

#### AI 页面摘要

1. 浏览到需要摘要的页面
2. 点击右侧面板的「生成摘要」按钮
3. AI 生成中文摘要，流式输出

### 场景二：Think — 深度思考

#### 编辑笔记

| 操作 | 快捷键 |
|------|--------|
| 新建笔记 | `Ctrl+N` |
| 保存笔记 | `Ctrl+S` |
| 打开每日笔记 | `Ctrl+D` |

- 编辑器支持 Markdown 语法高亮
- 输入 `[[` 触发 Wikilink 自动补全
- 编辑内容 500ms 后自动保存，失焦立即保存

#### Wikilink 双向链接

- 使用 `[[笔记标题]]` 创建到其他笔记的链接
- 右侧 Backlinks 面板自动显示所有引用当前笔记的其他笔记
- 点击链接跳转到对应笔记

#### AI 浮动助手

- 点击右下角 AI 按钮展开对话面板
- 支持选中文本后让 AI 续写/改进
- 支持三种 Provider：Ollama / OpenAI / Anthropic
- 流式输出，实时看到 AI 生成过程

### 场景三：Connect — 知识关联

#### 知识图谱

1. 自动从所有笔记的 Wikilink 构建知识图谱
2. 节点 = 笔记，连线 = 引用关系
3. 桥接节点（连接多个知识领域）以特殊颜色高亮
4. 支持缩放、拖拽平移

#### 筛选与导航

- 左侧 FilterPanel 按标签/类型/时间筛选
- 点击节点查看笔记详情
- 右键节点快速打开对应笔记

## AI 功能

### AI 对话

1. 点击右下角 AI 浮动按钮或进入设置打开 AI 面板
2. 输入消息，AI 流式回复
3. 可随时中止生成
4. 切换 Provider 不会丢失当前对话

### 上下文引用

在 AI 对话中使用以下语法引用上下文：

- `@note:笔记标题` — 引用一篇笔记
- `@web:URL` — 引用一个网页

### AI 配置

| 设置项 | 说明 |
|--------|------|
| Provider | 选择 AI 提供商（Ollama 本地/OpenAI/Anthropic） |
| Model | 选择模型 |
| Base URL | API 地址（Ollama 默认 `http://localhost:11434`） |
| API Key | 安全存储，不在日志或界面中明文显示 |

## 知识管理

### 笔记组织

- 所有笔记以纯 Markdown（.md）格式存储在 Vault 目录
- 支持 YAML Frontmatter 元数据
- 兼容 Obsidian / Foam 等工具

### 标签系统

- 在笔记中使用 `#标签名` 添加标签
- 标签可用于图谱筛选和搜索

### 笔记侧栏

- 左侧侧栏显示笔记目录树
- 点击笔记名称快速打开
- 右键菜单支持重命名/删除

## 数据同步

### Git 同步

1. 设置 → 同步设置 → 配置 Git
2. 自动提交变更并推送到远程仓库
3. 支持拉取远程更新

### WebDAV 同步

1. 设置 → 同步设置 → 配置 WebDAV
2. 输入服务器地址和凭据
3. 自动同步笔记文件

## 高级功能

### 无尽画布

1. 在 Connect 场景打开画布
2. 拖放笔记卡片到画布
3. 手动连线关联概念
4. 自动连线（虚线）与手动连线（实线）视觉区分
5. 画布自动保存到 `vault/.rf/` 目录

## 安全说明

- API Key 使用系统安全存储，永不明文记录

- 所有文件操作均在 Vault 目录范围内
